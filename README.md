# E-Digit

Mini app Vue per gestire un gioco con torre a tasselli a uno stand fieristico: selezione del tassello estratto, domanda privacy per area, schermata caduta torre e raccolta contatto locale.

## Comandi

```bash
npm install
npm run dev
npm run build
```

Il build statico finisce in `dist/` ed e pronto per GitHub Pages.

## Personalizzazione rapida

- Domande e aree: `src/data/privacyAreas.js`
- Logo: sostituire `src/assets/edigit-logo.svg`
- Testi principali: `src/App.vue`

La schermata contatto salva i nominativi nel browser dell'iPad. Da li puoi esportare un CSV.
